# Dealerships and Reviews Application

## Repository Name
`xrwvm-fullstack_developer_capstone`

## Project Name
**Dealerships and Reviews Application**

---

### Project Overview
The Dealerships and Reviews Application is a full-stack cloud application developed as the capstone project for the IBM Full Stack Cloud Developer Professional Certificate. The application allows users to browse a national dealership network, view dealers by state, inspect dealership details and customer reviews, register and log in to post new reviews with sentiment analysis, and manage automobile models and makes through a Django administration portal.

### Technology Stack
- **Front-End:** React, HTML5, CSS3, Bootstrap, JavaScript
- **Back-End:** Django, Python
- **Microservices & Database:** Node.js, Express, MongoDB (Dealership and Reviews API)
- **Sentiment Analysis:** IBM Watson / Natural Language Processing Microservice
- **Deployment & DevOps:** Docker, GitHub Actions (CI/CD), IBM Cloud Code Engine / Kubernetes
